# 🎤 Microphone Check

Microphone Check is a stylish React Native (Expo) application developed with modern technologies that allows you to track your daily microphone usage or visits. With its neon aesthetics and user-friendly interface, you can easily manage your data.

## ✨ Features

-   **📅 Interactive Calendar:** Visually track the days you've performed microphone checks.
-   **📈 Detailed Statistics:**
    -   Total number of microphone checks.
    -   Summary of visited days.
    -   Daily records.
    -   Most active months.
-   **💾 Data Management:**
    -   **Export:** Backup and share your data in JSON format.
    -   **Import:** Easily restore your backed-up data back into the application.
-   **🌐 Multi-Language Support:** Turkish, English, and Russian language options.
-   **🎨 Neon Design:** Modern and dark-mode focused aesthetics (using NativeWind).
-   **📱 Cross-Platform:** Smooth operation on both iOS and Android.

## 🛠️ Tech Stack

-   **Framework:** [Expo](https://expo.dev/) (React Native)
-   **Routing:** [Expo Router](https://docs.expo.dev/router/introduction/) (File-based routing)
-   **Database:** [Drizzle ORM](https://orm.drizzle.team/) + [Expo SQLite](https://docs.expo.dev/versions/latest/sdk/sqlite/)
-   **Styling:** [NativeWind v4](https://www.nativewind.dev/) (Tailwind CSS for React Native)
-   **Localization:** [i18n-js](https://github.com/fnando/i18n-js) & [expo-localization](https://docs.expo.dev/versions/latest/sdk/localization/)
-   **Animations:** [React Native Reanimated](https://docs.swmansion.com/react-native-reanimated/)

## 🚀 Getting Started

### Prerequisites

-   [Node.js](https://nodejs.org/) (LTS version recommended)
-   [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
-   Expo Go app (for mobile testing)

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/username/microphone-check.git
    cd microphone-check
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the application:
    ```bash
    npx expo start
    ```

4.  Open the Expo Go app on your mobile device and scan the QR code, or press `i` (iOS) or `a` (Android) from the keyboard to run it in an emulator.
